스토리내 작품이미지설정

설정

기본 모델

새 채팅을 시작할 때 쓸 모델. 채팅방에서 바꾼 건 그 방에만 남습니다.

최대 출력 길이

한 번에 생성할 최대 토큰 수. 제한 없음이면 값을 안 보내고 모델 기본값을 씁니다 — 사고 모델은 예산을 사고에 먼저 써서 빈 답이 나올 수 있으니 이쪽이 안전합니다.

장기 기억

대화가 길어지면 오래된 turn을 요약해 [장기 기억]으로 접어 넣습니다. 최근 N턴은 원문 그대로 남습니다. 요약에도 모델 호출이 한 번 듭니다.

사용량 자동 새로고침

사용량·잔액 조회는 모델을 부르지 않아 토큰을 쓰지 않습니다. 모델 창을 열 때는 주기와 상관없이 항상 새로 불러옵니다.

제공사 연결

~/.hermes/.env에서 자동으로 읽은 것들입니다. 여기서 키를 넣거나 보지 않습니다.

API 직접 추가

OpenAI 호환 주소면 뭐든 됩니다(/v1까지). 저장 전에 실제로 모델 목록을 불러와 확인합니다. 키는 data/providers.json에 평문으로 저장되고 이 페이지로 다시 내려오지 않습니다.

데이터

전부 크랙빌더/data 폴더의 JSON입니다. 삭제하면 되돌릴 수 없어요.
